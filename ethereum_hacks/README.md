# Ethereum 駭客攻擊案例庫（ethereum_hacks）

收錄 Ethereum 上的智能合約攻擊事件，資料來自 [DeFiHackLabs](https://github.com/SunWeb3Sec/DeFiHackLabs)：每起事件都有可在分叉鏈上重現的 Foundry PoC。每筆紀錄的中文摘要與根因，都是讀過該 PoC 程式碼後寫成的。

> ⚠️ **目前是草稿**：DeFiHackLabs 的 345 起 Ethereum 事件中，已撰寫 236 起，另有 105 起尚未撰寫（清單在 `research/evm_workflow_results/ethereum_remaining_inputs.json`）。這 236 筆紀錄還沒有經過第二位審查者獨立複核，`notes` 結尾都標有 `[Draft: not yet independently reviewed.]`。繼續的方法見根目錄的 `HANDOFF.md`。

資料結構、欄位與查詢方式和 [Solana 案例庫](../solana_hacks/README.md) 相同，漏洞模式使用 EVM 共用的 `hack_db/vuln_patterns/evm.json`（重入、權限控管、輸入驗證、簽章驗證、數值計算、業務邏輯、代理升級、編譯器漏洞等）。

## 收錄範圍與限制

- **只收錄 DeFiHackLabs 有 PoC 的合約攻擊**：交易所熱錢包被盜、釣魚與錢包盜取工具、跨鏈橋私鑰外洩等不在 DeFiHackLabs 的事件，需要網路搜尋額度才能補齊。
- **損失金額**：DeFiHackLabs 有寫美元金額就直接使用；只有 ETH / BNB 等代幣數量時，由撰寫者以當時的大約價格估算並在 `notes` 說明，其他代幣則留空。
- **純 rug pull / 部署者後門**已排除。
- 來源只使用 DeFiHackLabs PoC、其附帶的分析文章與攻擊交易連結。
